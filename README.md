## ⚙️ How to Run

### 1. Install Java

Install JDK 17 or later and verify your installation:

```bash
java -version
javac -version
```

### 2. Clone the Repository

```bash
git clone https://github.com/Chinmay-byte-afk/STEP-SEM-3-.git
```

### 3. Navigate to the Project

```bash
cd STEP-SEM-3-
```

### 4. Compile a Java Program

For example, compile the seat duplication checker:

```bash
javac "week 1/ExamHallSeatDuplicationChecker.java"
```

### 5. Run the Program

```bash
java -cp "week 1" ExamHallSeatDuplicationChecker
```

### Running Other Programs

Replace the filename and class name with the program you want to execute.

For example:

```bash
javac "week 1/TypingSpeedAccuracyChecker.java"
java -cp "week 1" TypingSpeedAccuracyChecker
```

```bash
javac "week 1/TrafficSignalStreakAnalyzer.java"
java -cp "week 1" TrafficSignalStreakAnalyzer
```

```bash
javac "week 1/WarehouseInventoryBalancer.java"
java -cp "week 1" WarehouseInventoryBalancer
```

```bash
javac "week 1/MovieReviewWordLengthProfiler.java"
java -cp "week 1" MovieReviewWordLengthProfiler
```
